# B-03 — Does S3 (filter) get a verdict?

The fourth open decision of the brief. S3 is run and measured, but no research question names it,
so as written its numbers are descriptive. A green and red can still be added — **only now**, while
the window is open: a threshold written after the first filter run is the move the brief forbids.

- **Recommendation: leave it descriptive.** Every keystroke re-filters 2,000 items in the shared
  module and rebuilds the list; what it would isolate is the same bridge and recomposition cost RQ3
  and RQ5 already price, and a sixth question with thresholds nobody has a prior for is a question
  likely to end grey. Reporting it with median and IQR per variant, and saying so, costs nothing.
- If the owner wants a verdict, the unit and both thresholds are written here and appended to
  BRIEF.md as an amendment before [B-01](B-01-pins-and-the-amendment-window.md) closes the window.

- AC: the owner's answer, dated, in this file; if it is "verdict", the unit (for instance the
  longest hitch during typing, or the p95 of keystroke-to-frame latency from signposts), green, red
  and the device are in BRIEF.md before the window closes.
- Anchors: `harness/` (target), `docs/research/source-brief.md`.
